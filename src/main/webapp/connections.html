유저 생성

새 데모 유저를 만든다. 템플릿을 고르면 유저 생성과 동시에 그 거래 패턴까지 바로 적용된다 (건너뛰면 빈 계정만 만들어지고, 아래 "유저 관리"에서 나중에 붙일 수 있다).

시나리오 생성

거래 패턴을 JSON으로 작성해 재사용 가능한 템플릿으로 저장한다. 유저에게 바로 적용하지는 않는다 — 저장된 템플릿은 위 "유저 생성"이나 아래 "유저 관리"에서 골라 적용한다.

과거 데이터 기반 시나리오 생성

종목별 실제 과거 종가(네이버 일별시세)로 매수 거래를 채운 템플릿을 만들어 저장한다. 본 서비스 분석 기능이 요구하는 최소 기간치 거래이력을 손으로 가격을 지어내지 않고 준비할 때 쓴다. 종목코드를 비우면 지금 시점 시가총액 순위(코스피 상위 20 + 코스닥 상위 10)를 실시간 조회해 기본 바스켓으로 쓴다. 저장만 하고 유저에게 적용하지는 않는다.
